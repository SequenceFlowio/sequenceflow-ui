# Kennis voor de SequenceFlow-assistent

Deze documenten zijn bedoeld om te uploaden in onze eigen Support One-werkruimte (Jouw kennis), zodat de assistent vragen van onze eigen klanten kan beantwoorden. Zie plan §9 in docs/plan-prijzen-en-mascotte-vervolg.md.

- `prijzen-en-facturen.md` — pakketten, wat telt als afgehandeld gesprek, budget, btw, facturen, opzeggen.
- `koppelen-en-starten.md` — mailbox koppelen, kennis toevoegen, eerste concept, automatisch versturen.
- `veelgestelde-vragen.md` — de meest voorkomende vragen en wanneer we doorzetten naar een mens.

Bijwerken bij elke prijs- of productwijziging (stand: 6 november 2026).
